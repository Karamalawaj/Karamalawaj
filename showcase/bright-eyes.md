# Bright Eyes — Portfolio Showcase

> Portfolio showcase only. The complete implementation is maintained separately and is intended to remain private. Sensitive configuration, data, internal architecture, and implementation details are intentionally not published here.

Bright Eyes is a healthcare-oriented Flutter application focused on ophthalmology workflows, patient interactions, booking, and presenting patient-related results in a clear mobile experience.

## What this showcase highlights

- Mobile product design and Flutter implementation experience
- Patient-facing appointment and profile workflows
- Structured presentation of clinical information
- Practical use of Firebase-backed application services
- UI/UX decisions for a real-world healthcare use case

## Technology overview

Flutter, Dart, Firebase, and related mobile application tooling.
