# Portfolio Source Policy

This GitHub profile presents selected projects through public, portfolio-safe showcase material.

- Full source repositories may remain private to protect implementation details, internal architecture, data, credentials, and proprietary work.
- Public showcase material is intentionally limited to high-level product context, selected features, technology summaries, screenshots, and non-sensitive architecture notes.
- Public showcase content is not a source-code release and does not grant permission to copy, redistribute, or reuse private implementation details.
- Access to full source code may be discussed privately when appropriate for technical review, due diligence, or recruitment.

This policy applies across the portfolio, including projects whose complete implementation is maintained in private repositories.
